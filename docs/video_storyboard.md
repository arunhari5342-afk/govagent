# GovAgent 10-Second Explainer Storyboard

## Scene 1 — 0–3 seconds

User asks an enterprise policy question.

Visual:
User → GovAgent

## Scene 2 — 3–6 seconds

Supervisor routes the request.

Visual:
Supervisor → Policy RAG / Action Agent

## Scene 3 — 6–8 seconds

Governance controls an external action.

Visual:
Action → Approval Gate → Human Reviewer

## Scene 4 — 8–10 seconds

Approved action executes and is audited.

Visual:
Approval → MCP Tool → PostgreSQL → Audit Log
